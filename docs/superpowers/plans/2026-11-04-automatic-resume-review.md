# 上传简历自动初评实施计划

**Goal:** 已确认简历绑定会话后自动给出简短、有依据的开场初评，按会话和简历版本只触发一次。

**Architecture:** 复用数据库Turn队列、Worker和SSE；绑定接口入队一次性Skill任务，队列在会话锁内幂等；自动任务可排在当前回复后。消息标记自动来源，UI不展示合成用户提问，后续不继承自动Skill。

**Tech Stack:** FastAPI、SQLAlchemy/PostgreSQL、Vue3、pytest、Node test runner。

**Spec:** 本对话已确认的“确认简历→正在阅读简历→流式初评→选择下一步”；不新增路由或独立任务系统。

## 全局边界

- 仅本地，保留原有dirty工作区，不提交/部署；不自动调用using-superpowers。
- PC优先，不新增手机或平板专项。只实现功能，不顺带修复此前审计中的无关缺陷。
- Skill自动挂载仅作用于初评；无JD也给简历建议，有JD结合岗位；不编造数据，不自动改写原简历。
