# 求职助手前 15 秒宣传 Demo 实施计划

**目标：** 按已确认的 120 秒脚本，仅制作 00:00–00:15 的登录与开启对话，输出可播放 MP4，供用户评估风格。

**设计依据：** 本聊天已确认的分镜与 Remotion 选型；保持 1920×1080、60fps，15 秒共 900 帧。范围截至开启对话与助手反馈，不提前制作简历、检索或发送镜头。

**实现结构：** 独立目录 `output/remotion-career-demo15/`。使用实际 Vue 前端组件和本地演示 API 状态采集素材，Remotion 处理取景、共享区域过渡、文字、光标和声音。所有生成内容标明为演示，不连接生产或实际发送消息。

- [x] 采集：启动单独前端端口 5180，使用 Playwright 采集登录、工作区、新对话与回答的高清状态，记录素材来源和坐标。
- [x] 动效：在独立 Remotion 项目实现登录推近、点击扩展遮罩、工作区拉回、对话焦点移动与结果呈现。关键元素采用帧驱动，保持文本清晰。
- [x] 声音：本地合成简洁配乐与操作反馈，不使用付费外部生成服务。
- [x] 验证：检查关键帧、转场连续帧及整个 15 秒预览；渲染 900 帧 MP4，核对分辨率、帧率、时长和音轨。
- [x] 交付：提供 MP4、封面、可编辑工程和制作说明，记录已验证结果及风格调整边界。

**关键命令：** `npm run dev -- --port 5180`（web-ui）；`node scripts/capture.mjs`；`npx remotion studio`；`npx remotion render CareerDemo15 out/career-demo15.mp4 --is-production=false`。

**验证边界：** 此次只验证视频制作与真实前端呈现，演示回复不代表真实模型响应延迟，不执行平台注册、验证码发送或外部招聘沟通。

**完成结果：** `output/remotion-career-demo15/out/career-demo15-preview.mp4` 已生成，900 帧、1080p60，视频轨 15 秒；采集无页面错误，ESLint / TypeScript 通过，最终视频 15 处取帧与完整解码通过。调用链、素材清单和后续边界见工程内 `制作说明.md`。
