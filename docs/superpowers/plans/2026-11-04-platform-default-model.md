# 平台默认DeepSeek V4 Pro实施计划

目标：任何用户进入主对话默认使用平台共享DeepSeek V4 Pro，无需个人配置Key；界面、API省略选择和自动初评一致。

方案：新增platform_default选择策略，网关按配置精确解析共享Provider/Model ID，保留显式免费和指定模型选择。模型列表返回无密钥默认描述；前端使用它初始化和重置，历史明确指定模型可恢复，历史免费自动选择回到平台默认。默认不可用时联系管理员，不静默换模型。
