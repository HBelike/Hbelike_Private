# 面试大师长连接实施与验收

目标来自同日的[跨小时故障审查](../../reviews/2026-11-19-live-interview-hour-and-incidents.md)。以当前主线合入 `68a2023` 的音频转发策略，复用既有会话、数据库、WebSocket 事件与流式回答服务。

1. **收音和转写**。每轨提供六秒有界缓冲，心跳独立收发。用供应商句子标识去重，结束输入后读完尾句再释放连接。用同一音频帧后连续返回两句和延迟尾句覆盖回归。
2. **组题和追问**。保持临时和最终字幕即时展示。背景片段与实际问句合并；独立问题、祈使式问题和自然追问都要能够生成答案。验证并发转写、队列等待、指代、模型故障及数据库状态恢复。
3. **前端接续**。保留当前授权音轨和会话，暂存短断期间尚未发送的音频，明确超出窗口后的缺失；恢复连接后保持问题版本和历史。采集端按连续相位重采样，并区分候选人麦克风与主音轨结束。
4. **多服务验收**。通过本机 WebSocket、独立 ASR WebSocket 和模型 HTTP SSE 服务、实际 PostgreSQL 仓储，核对最终转写、答案版本、心跳、结束事件和持久化结果。分别记录实际经过时间与合成音频量。覆盖六十分钟以上、并发会话、断线重连、最新一题及收尾。单独验证真实云端服务需要相应凭据和用量，发布属于独立操作。
